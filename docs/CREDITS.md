# Credits

## Code, art and sound

Everything in the game so far is made in code in this repository:

- **3D models**: built procedurally (cake tiers, piping, decorations, the
  bakery set). No model files.
- **Textures and shaders**: written for this project (`art/shaders/`) or
  generated at run time (noise, soft particles).
- **Sound effects and ambience**: synthesised at start-up by
  `scripts/audio/synth.gd` from noise and sine tones. No recordings or
  sound libraries are used.

## Fonts

- The interface, topper signs, plaques and fondant letters currently use
  the system font Segoe UI (on the player's own machine; not shipped with
  the game). A bundled font is planned for milestone G; its licence will
  be listed here.
